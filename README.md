🎟️ Online Ticket Booking Ads Simulation

A simple Online Ticket Booking Simulation developed using HTML, CSS, and JavaScript. This project demonstrates basic ticket booking functionality along with advertising concepts such as banner advertisements, sponsored offers, ad impressions, and ad click tracking.

📌 Features

🎫 Online ticket booking simulation

📍 Enter departure and destination

📅 Select travel date

👥 Select number of passengers

💰 Automatic ticket price calculation

✅ Booking confirmation with a generated booking ID

📢 Banner advertisement

💳 Sponsored advertisement offer

📊 Advertisement impression tracking

🖱️ Advertisement click tracking

📱 Responsive design for mobile and desktop

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and responsive design

JavaScript – Booking functionality and advertisement tracking

💡 Advertising Concepts

This project demonstrates basic advertising concepts:

Banner Ad: Displays a promotional advertisement at the top of the page.

Sponsored Ad: Displays a sponsored payment offer.

Ad Impression: Counts when an advertisement is displayed.

Ad Click: Tracks clicks on advertisements.

User Engagement: Demonstrates how users interact with advertisements.
